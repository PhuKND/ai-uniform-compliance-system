HƯỚNG DẪN SỬ DỤNG UNIFORM-AI TÍCH HỢP
======================================

1. MỤC ĐÍCH DỰ ÁN
-----------------

`uniform-ai` là server Flask duy nhất cho hệ thống đánh giá tuân thủ nội quy đồng phục học sinh trung học cơ sở.

Khi chạy:

```powershell
python app.py
```

hoặc 
cd C:\Users\KaNija\Desktop\DATN\Code3\UNIFORM-LIB\uniform-ai
.\.venv\Scripts\Activate.ps1
python app.py



Hoặc
& c:\Users\KaNija\Desktop\DATN\Code3\uniform-lib\uniform-ai\.venv\Scripts\Activate.ps1
python app.py

server tại `http://127.0.0.1:5001` cung cấp toàn bộ AI:

- Nhận diện khuôn mặt học sinh bằng InsightFace.
- Đánh giá đồng phục bằng Grounding DINO, SCHP ATR, Florence-2 và RuleEngine.
- Nhận diện 4 thành phần đồng phục bằng YOLOv8.
- API kết hợp định danh học sinh + đánh giá đồng phục.

Không cần chạy server riêng trong `face-recognition-service/`.

2. SCHEMA ĐỒNG PHỤC CHÍNH THỨC
------------------------------

Các class đồng phục đang hoạt động chỉ gồm đúng 4 key:

```text
0: ao_so_mi_trang
1: ao_doan_thanh_nien
2: quan_tay_dai_den
3: khan_quang_do
```

Các nhãn cũ như badge, emblem, belt, skirt, school badge, school emblem, huy_hieu, phu_hieu, that_lung, trousers_or_skirt chỉ là ghi chú lịch sử và không được dùng trong logic đang chạy.

4. FILE BẮT BUỘC TRONG `yolov8_6class/`
--------------------------------

Đặt các file sau trong `yolov8_6class/`:

```text
best.pt
class_names.json
classes.txt
data.yaml
model_provenance.json
training_configuration.json
validation_metrics.json
Train_uniform_AI_YOLOv8_(6) (1).ipynb
```

Production inference chỉ dùng `yolov8_6class/best.pt`. Không fallback sang `last.pt`.

`class_names.json`, `classes.txt`, `data.yaml` phải khớp đúng 6 class chính thức, đúng thứ tự:

```text
0 ao_so_mi_trang
1 ao_doan_thanh_nien
2 quan_tay_dai_den
3 khan_quang_do
4 quan_short_tay_den
5 quan_dai_trang
```

Nếu sai thứ tự hoặc sai tên class, YOLOv8 V2 sẽ bị báo unavailable.

Mục đích: đánh giá đồng phục đầy đủ.

Content-Type: `multipart/form-data`

Body:

```text
image: required image file
confidence: optional, default 0.25
image_size: optional, default 640
save_annotated: optional, default true
```

PowerShell:

```powershell
Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:5001/api/uniform/evaluate" `
  -Form @{ image = Get-Item ".\test.jpg" } | ConvertTo-Json -Depth 12
```

```powershell

  http://127.0.0.1:5001/api/uniform/evaluate
```

14. GIẢI THÍCH JSON ĐỒNG PHỤC
-----------------------------

`required_items`: trạng thái 4 thành phần chính thức.

`uniform_policy`: chính sách áo trắng hoặc áo Đoàn, yêu cầu khăn quàng đỏ, số component đạt.

`appearance`: so vin, nhăn, bẩn, rách/hỏng.

`overall`: kết luận `compliant`, `partially_compliant`, `non_compliant`, hoặc `needs_review`.

`notes`: cảnh báo và lỗi stage phụ nếu có.

`yolov8`: kết quả detection YOLOv8, bbox và URL ảnh annotated.

```kotlin
interface AiApi {
```

19. TROUBLESHOOTING
-------------------

`No module named insightface`:


Hoặc cài lại đầy đủ:

```powershell
pip install -r requirements.txt
```

`No module named onnxruntime`:


InsightFace model download chậm:
- Lần đầu gọi `/api/face/identify`, `/api/face/verify`, `/api/face/enroll` có thể tải model `buffalo_l`.
- Kiểm tra mạng hoặc đặt `INSIGHTFACE_MODEL_ROOT` tới thư mục đã có model.

CPU chậm:
- Grounding DINO, Florence-2, SCHP và InsightFace đều nặng khi chạy CPU.
- Nếu có GPU NVIDIA, cài PyTorch CUDA và cấu hình provider phù hợp.

CUDA provider không khả dụng:
- Giữ `INSIGHTFACE_PROVIDERS=CPUExecutionProvider` nếu không chắc chắn.
- Chỉ dùng CUDA provider khi đã cài đúng `onnxruntime-gpu`, driver và CUDA.

`NO_FACE_FOUND`:
- Ảnh không có mặt rõ, mặt quá nhỏ, bị che hoặc ánh sáng kém.

`MULTIPLE_FACES_FOUND`:
- API enroll và verify yêu cầu đúng 1 khuôn mặt.
- Cắt ảnh chỉ còn một học sinh rồi thử lại.

`STUDENT_ALREADY_EXISTS`:
- Dùng `/api/face/enroll-sample` để thêm góc mặt mới.

`STUDENT_NOT_FOUND`:
- Kiểm tra `student_id` hoặc enroll học sinh trước.

`CORRUPTED_STORED_EMBEDDING`:
- File `.npy` trong `storage/embeddings/` bị thiếu hoặc hỏng.
- Có thể restore từ backup hoặc enroll lại học sinh.

Storage path sai:
- Kiểm tra `FACE_STORAGE_DIR`, `FACE_METADATA_FILE`, `FACE_EMBEDDING_DIR`.
- Chạy `/api/face/reload` sau khi copy dữ liệu.

Port 5001 đã được dùng:

```powershell
$env:UNIFORM_PORT="5002"
python app.py
```

YOLO `best.pt` missing:
- Đặt `yolov8_6class/best.pt` đúng vị trí.
- Production không dùng `last.pt`; nếu thiếu `best.pt` thì YOLOv8 V2 phải báo unavailable.

YOLO class mismatch:
- Kiểm tra `class_names.json`, `classes.txt`, `data.yaml` phải đúng 6 class chính thức và đúng thứ tự.

SCHP checkpoint missing:
- Đặt file:

```text
weights/exp-schp-201908301523-atr.pth
```

`transformers==4.49.0` issue:
- Dự án đang pin `transformers==4.49.0` để ổn định Florence-2.
- Không tự nâng cấp nếu chưa test lại toàn bộ pipeline.

CORS bị chặn từ React:
- Thêm domain frontend vào `UNIFORM_CORS_ORIGINS`, ví dụ:

```text
UNIFORM_CORS_ORIGINS=http://localhost:5173,http://localhost:3000
```

Android không gọi được server:
- Không dùng `localhost` từ emulator/device.
- Dùng IP LAN của laptop và đảm bảo firewall cho phép port 5001.

PowerShell `Invoke-RestMethod -Form` không tồn tại:
- Tham số `-Form` cần PowerShell phiên bản mới.
- Dùng `curl.exe -F` thay thế trên Windows PowerShell cũ.
POSE-BASED TARGET STUDENT VALIDATION
------------------------------------

He thong da bo sung YOLO pose de chon dung 1 hoc sinh muc tieu:

- Model mac dinh: `yolov8n-pose.pt`.
- Cach chon: nguoi co pose/body bbox lon nhat, co cong them pose confidence va so keypoint hop le.
- Chi hoc sinh duoc chon moi duoc ve skeleton, nhan dien khuon mat va cham diem dong phuc.
- Khuon mat chi duoc nhan dien neu face bbox khop vung dau cua pose duoc chon.
- YOLO raw detections duoc tach thanh `accepted_detections` va `rejected_detections`.
- Diem dong phuc chi dung cac YOLO detections nam trong `accepted_detections`.
- Backend luu va tra ve 1 anh preview cuoi cung duy nhat sau khi validate pose-YOLO.
- Anh preview cuoi cung co ca skeleton cua hoc sinh duoc chon va YOLO bbox hop le/bi loai.
- Frontend nen hien thi `processed_image_url` hoac `final_annotated_image_url`.
